Almost everything in APM has a key. Press <Kbd>⌘</Kbd><Kbd>/</Kbd> (or **Help → Keyboard Shortcuts**) to see the main ones inside the app. The command menu (<Kbd>⌘</Kbd><Kbd>K</Kbd>) finds the rest.

The tables use macOS keys. On Windows and Linux:

| macOS | Windows and Linux |
|---|---|
| <Kbd>⌘</Kbd> | <Kbd>Ctrl</Kbd> |
| <Kbd>⌥</Kbd> | <Kbd>Alt</Kbd> |
| <Kbd>⇧</Kbd> | <Kbd>Shift</Kbd> |
| <Kbd>⌫</Kbd> | <Kbd>Backspace</Kbd> |
| <Kbd>↵</Kbd> | <Kbd>Enter</Kbd> |

These shortcuts work while the vault is unlocked. While a dialog is open, only <Kbd>⌘</Kbd><Kbd>K</Kbd> and the dialog's own keys work.

Two platform details:

- The in-app list that <Kbd>⌘</Kbd><Kbd>/</Kbd> opens uses Mac symbols on every platform. On Windows and Linux, read <Kbd>⌘</Kbd> there as <Kbd>Ctrl</Kbd>.
- On a Mac, the app's own shortcuts also answer to <Kbd>Ctrl</Kbd> in place of <Kbd>⌘</Kbd>, so <Kbd>Ctrl</Kbd><Kbd>K</Kbd> opens the command menu too. Menu-bar entries need <Kbd>⌘</Kbd>.

The in-app list ("Every action in APM has a key. The command menu finds the rest.") has four groups: **Vault**, **Selected item**, **List** and **App**. The tables below cover everything in it, and more.

## The selected item

These work in the vault view when an item is selected.

| Keys | Action |
|---|---|
| <Kbd>⇧</Kbd><Kbd>⌘</Kbd><Kbd>C</Kbd> | Copy the main secret (a login's password, an API key's key and so on) |
| <Kbd>⇧</Kbd><Kbd>⌘</Kbd><Kbd>U</Kbd> | Copy the username |
| <Kbd>⇧</Kbd><Kbd>⌘</Kbd><Kbd>T</Kbd> | Copy the one-time code |
| <Kbd>⇧</Kbd><Kbd>⌘</Kbd><Kbd>O</Kbd> | Open the website in your browser |
| <Kbd>⌘</Kbd><Kbd>E</Kbd> | Edit |
| <Kbd>⌘</Kbd><Kbd>⌫</Kbd> | Delete (move to Trash). In Trash, delete permanently. |
| <Kbd>Space</Kbd> | Quick Look the item under the pointer, or the selected one |

When there is nothing to act on, APM says so: **Nothing to copy**, **No username on this item**, **No one-time code for this item** or **No website on this item**. <Kbd>⇧</Kbd><Kbd>⌘</Kbd><Kbd>O</Kbd> opens a login's website, or the first of its other websites, and a Docker registry's address.

## The item list

| Keys | Action |
|---|---|
| <Kbd>⌘</Kbd><Kbd>F</Kbd> | Jump to the list's search field |
| <Kbd>↵</Kbd> (in the search field) | Move to the selected item's first field |
| <Kbd>Esc</Kbd> (in the search field) | Empty the search field |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd> | Previous or next item |
| <Kbd>⇧</Kbd><Kbd>↑</Kbd> <Kbd>⇧</Kbd><Kbd>↓</Kbd> | Extend the selection |
| <Kbd>⌘</Kbd>-click | Add an item to the selection, or remove it |
| <Kbd>⇧</Kbd>-click | Select a range |
| <Kbd>⌘</Kbd><Kbd>A</Kbd> | Select every item in the list |
| <Kbd>Esc</Kbd> | Clear a multiple selection |
| Double-click | Edit the item |
| Right-click | The item menu, or the selection menu |

## Editing

| Where | Keys | Action |
|---|---|---|
| Editing an item | <Kbd>⌘</Kbd><Kbd>S</Kbd> | Save |
| Editing an item | <Kbd>Esc</Kbd> | Cancel (asks first if you made changes). With a menu or the generator open, <Kbd>Esc</Kbd> closes that first |
| Renaming a passkey on a login | <Kbd>Esc</Kbd> | Stop renaming |
| New item dialog | <Kbd>⌘</Kbd><Kbd>↵</Kbd> | Save the item |
| Note editor | <Kbd>⌘</Kbd><Kbd>S</Kbd> | Save the note |
| Note editor | <Kbd>Tab</Kbd> | Insert two spaces |

## Other screens

| Where | Keys | Action |
|---|---|---|
| Lock screen | <Kbd>↵</Kbd> | Unlock with the password you typed |
| Command menu | <Kbd>↑</Kbd> <Kbd>↓</Kbd> | Move through results |
| Command menu | <Kbd>↵</Kbd> | Run the highlighted entry |
| Command menu | <Kbd>Esc</Kbd> | Close |
| Quick Look | <Kbd>↑</Kbd> <Kbd>↓</Kbd> | Show the previous or next item |
| Quick Look | <Kbd>Space</Kbd> or <Kbd>Esc</Kbd> | Close |
| Authenticator page | <Kbd>1</Kbd> to <Kbd>9</Kbd> | Copy the code in that position |
| Generator in a field | <Kbd>R</Kbd> | Generate another value (when the cursor is not in a text field) |
| Generator in a field | <Kbd>Esc</Kbd> | Close |
| Right-click menu | <Kbd>Esc</Kbd> | Close |
| Six-digit code boxes | <Kbd>←</Kbd> <Kbd>→</Kbd> | Move between boxes. Typing a digit moves to the next box, <Kbd>⌫</Kbd> in an empty box goes back, and pasting a code fills every box |
| Menus and dialogs | <Kbd>Esc</Kbd> | Close |

The **Password generator** window shows <Kbd>R</Kbd> on its **Generate another** button, but the key only works in the generator inside a field.
