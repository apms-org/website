This is the complete list of `pm` 12.0.0 commands, checked against the source. Each row links to its full entry with usage, flags and examples. Run `pm <command> --help` for the same usage in your terminal.

## Global flags

`-v` and `-h` work with every command. `--version` works only on `pm` itself:

| Flag | Meaning |
|---|---|
| `-v`, `--vault <path>` | Use this vault file for this command. Overrides `APM_VAULT_PATH` and the default: a `vault.dat` next to `pm` if there is one, otherwise `~/.apm/vault.dat`. See [Where the vault lives](/docs/cli/vault-basics#where-the-vault-lives) |
| `-h`, `--help` | Show usage for the command |
| `--version` | Print the version number only, for example `12.0.0`. Run it as `pm --version`; after a command name it is an unknown flag |

`-v` means `--vault`, not `--version`.

## Hidden commands

These don't appear in `pm --help`. Other programs start them; you normally don't run them yourself.

| Command | Started by |
|---|---|
| `pm desktop` | The desktop app, as its background engine. It speaks JSON over stdin and stdout |
| `pm mcp serve --token <token>` | Your AI client. See [AI agents](/docs/agents/setup) |
| `pm extension host [origin]` | The browser, through native messaging. Chromium also starts `pm` directly with the extension's `chrome-extension://` origin as the first argument, which runs the same host |

## Removed and renamed commands

Older guides, scripts and the previous documentation site use commands that no longer exist. `pm` answers them with an error such as `Error: unknown command`, a not-found message or a usage screen, and still exits with status 0, so check old scripts by hand.

| Old command | Now |
|---|---|
| `pm plugins …` (`installed`, `list`, `market`, `add`, `install`, `push`, `remove`, `search`, `local`, `access`, `run`) | Removed in 12.0 with the plugin marketplace. There is no replacement |
| `pm passkeys …` (`list`, `rename`, `rm`, `remove`) | Removed. A login's passkeys show when you open it with [`pm get`](/docs/cli/commands-items#pm-get), and its edit screen renames or removes them |
| `pm bridge serve`, `pm bridge status`, `pm bridge token`, `pm bridge rotate` | [`pm extension serve`](/docs/cli/commands-sync#pm-extension-serve), [`pm extension status`](/docs/cli/commands-sync#pm-extension-status), [`pm extension token`](/docs/cli/commands-sync#pm-extension-token) and [`pm extension rotate`](/docs/cli/commands-sync#pm-extension-rotate). `pm bridge` has no alias |
| `pm autofill …`, `pm autocomplete …` | Removed. Windows autofill, its hotkey and fill sequences are gone. Use the [browser extension](/docs/extension) |
| `pm autocomplete link-totp` | [`pm totp link <entry> <domain>`](/docs/cli/commands-items#pm-totp-link) |
| `pm audit` | [`pm logs`](/docs/cli/commands-security#pm-logs) |
| `pm readonly <minutes>` | [`pm mode readonly <minutes>`](/docs/cli/commands-vault#pm-mode-readonly) |
| `pm space remove`, `pm space current` | Removed. `pm space list` marks the current space with `*`; delete spaces in the desktop app |
| `pm cloud autosync` | [`pm cloud auto-sync --true`](/docs/cli/commands-sync#pm-cloud-auto-sync) |
| `pm import json\|csv\|txt <file>` | [`pm import <file>`](/docs/cli/commands-items#pm-import). The format is detected; `--from` overrides it |
| `pm import … --decrypt` | `-p`, `--password`. `pm` asks for the password when a file needs one |
| `pm export json\|csv\|txt` | [`pm export --format apm\|cxf\|bitwarden\|csv\|txt`](/docs/cli/commands-items#pm-export). The command takes no positional arguments |
| `pm export … --no-password` | `--without-password` |
| `pm policy load ./policies/` | [`pm policy load <name>`](/docs/cli/commands-security#pm-policy-load). Loads one policy by its `name` from the `policies` folder next to the vault |
| `pm completion` | Not available. `pm` has no shell completion |
| `pm-team dept info`, `pm-team user role` | `pm-team dept list` and `pm-team user promote`. See [Team edition](/docs/cli/team-edition) |
| `pm-team init "<org>"` | `pm-team init <org> <admin-username>` |
