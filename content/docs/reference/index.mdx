## Defaults at a glance

| Setting | Default |
|---|---|
| Vault file | `~/.apm/vault.dat` (or a `vault.dat` next to `pm`) |
| Encryption profile | Recommended by `pm setup` for your machine; `standard` otherwise |
| Auto-lock | 15 minutes idle, 1 hour maximum, lock on sleep |
| Extension bridge | `127.0.0.1:41417` |
| Ephemeral session lifetime | 15 minutes, read-only |
| Generated password | 16 characters with `pm gen`, 20 in the app's generator |
| One-time codes | 6 digits, 30 seconds, SHA-1 |
| Recovery codes | 10 |
| Trustee shares | 2 of 3 |
